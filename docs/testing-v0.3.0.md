# Проверка v0.3.0

## Интерфейс

Компоновка 720 × 480 DIP, общие отступы 24 DIP. Действия находятся непосредственно под списком. В собственном заголовке есть тема, сворачивание и закрытие; кнопки разворота нет. Диалоги используют заголовок ToolWindow без кнопок сворачивания/разворота.

Отрисован настоящий WPF-интерфейс обеих тем: список, настройки, пустое состояние, 12 строк, длинное название, диалог с ошибкой, колесо с 3 и 12 секторами. Дополнительно созданы снимки списка в масштабе 125%. Проверены контраст, отсутствие прокрутки короткого списка, доступность прокрутки длинного и положение действий выше футера. Снимки создаются из тестовых данных; пользовательские настройки не публикуются.

Значки Блокнота и Калькулятора запрашиваются из установленных пакетов Windows через IShellItemImageFactory. Для остальных файлов и при недоступности пакета используется Windows Shell image list. Визуальная подмена узнаваемых приложений убрана. Только отсутствующий значок получает общий символ. Иконки управления — настоящие векторные контуры Freepik UIcons; источник и лицензия включены.

В интерактивном окне через computer-use проверены новая сетка, реальные значки и отсутствие квадратика разворота. Дальнейшая автоматизация ввода прервана обнаружением пользовательского ввода; переключение обеих тем и бинды не засчитываются как завершённые ручные проверки. Они проверены отрисовкой и автоматическими проверками поведения. Отдельного ручного прогона в игре или браузере F11 для этой версии не было.

## Автоматические проверки

Локально прошли:

- Release build: 0 ошибок, 0 предупреждений.
- `--self-test`: 16 294 утверждения, включая предыдущие регрессии, мышиные бинды, оформление и размытый материал.
- `--native-registration-test`: 400 проверок, 100 настоящих циклов регистрации/снятия Raw Input.
- `--hook-test`: 100 проверок переключения настоящих глобальных мышиных хуков. Для клавиатуры хук снимается.

Мышиные проверки покрывают MMB/X1/X2, отпускание, Esc, сочетание с Ctrl, защиту от запуска удерживаемой кнопкой после записи и разбор Windows-сообщений. ЛКМ/ПКМ, колесо прокрутки и движение проходят без подавления. Тесты не имитируют физическую мышь.

Проверка BlurEffect использует контрастную синтетическую текстуру: результат содержит промежуточные значения пикселей. После закрытия снимок освобождается. Цветовая анимация темы заканчивается за 170 мс, учитывает системную настройку анимаций и не оставляет активного animation clock.

В [Windows CI 41722815334](https://github.com/palychdev/Orbit/actions/runs/41722815334) на коммите `45eb9fd` прошли все перечисленные проверки и ещё 400 проверок настоящего колеса: 40 циклов открытия/закрытия без фокуса, восстановление позиции и ограничений курсора, регистрация и снятие Raw Input. Отчёты и снимки доступны в artifact `test-reports`. Локально тест с перемещением курсора не запускается во время пользовательской работы с мышью.

В переносимой сборке с локальной средой .NET отдельно прошли `--self-test`, `--native-registration-test` и `--hook-test` с теми же результатами.

## Фоновая работа

В обычном режиме нет периодического захвата экрана или опроса мыши. Raw Input регистрируется только на время колеса. Глобальный мышиный хук устанавливается только для мышиного бинда, события движения проходят короткую ветку без выделений памяти. Снимок размытия создаётся один раз при открытии и освобождается при закрытии.

Локальный замер переносимой сборки: 2 секунды прогрева и около 8 секунд в трее с тремя стандартными приложениями. Для F8: Working Set 109,4 MiB, Private Memory 46,4 MiB; для Mouse 4: 109,6 / 46,8 MiB. Прирост процессорного времени в обоих коротких замерах не зарегистрирован, выделено около 8 KiB. Это наблюдение на одном компьютере, а не гарантия нулевого CPU или универсального объёма памяти.

Полноэкранные игры, защищённый экран и эксклюзивный fullscreen сохраняют ограничения из README. Успешный тест жизненного цикла окна не подтверждает совместимость с конкретной игрой.
