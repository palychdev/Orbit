# Изменения

## v0.1.1 — 2026-11-03

- Исправлена зависимость выбора от фокуса: Raw Input регистрируется с INPUTSINK до показа колеса.
- Убрана отмена только из-за события Deactivated; отказ Windows в активации не прерывает ввод.
- Открытие стало транзакционным: при ошибке выполняются восстановление курсора, удаление регистрации и скрытие окна.
- Исправлена обработка Esc и отпускания модификаторов, добавлена отмена через Alt+Tab.
- Добавлены регрессионные проверки, тесты настоящей регистрации Windows API и Windows CI.

Проверки мыши в реальном «Пуске», браузере F11 и игре пока не подтверждены. Подробности: [docs/testing-v0.1.1.md](docs/testing-v0.1.1.md).

## v0.1.0 — 2026-11-03

Первая версия Orbit для Windows x64.

- Радиальное меню в центре экрана, где находится мышь.
- Выбор приложения по направлению движения при скрытом курсоре.
- Глобальный клавиатурный бинд; F8 по умолчанию.
- Запуск или переключение на существующее окно приложения.
- До 12 программ, добавление .exe и ярлыков, изменение порядка.
- Настройка размера, чувствительности и прозрачности.
- Работа в трее, сохранение настроек и автозапуск по желанию.
- Переносимая сборка с локальной средой .NET.

Проверено: сборка, 87 автоматических проверок, отрисовка настроек и колеса.
Полный сценарий с физической мышью и переключением приложений требует ручной проверки.
